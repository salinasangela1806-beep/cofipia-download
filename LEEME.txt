¿CUÁL ARCHIVO EJECUTAR? — LEE ESTO PRIMERO
═══════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────┐
│  INSTALAR_COFIPIA.bat                                           │
│  ─────────────────────────────────────────────────────────────  │
│  USO: Para TI, en tu propio equipo, durante el desarrollo.     │
│                                                                 │
│  Qué hace:                                                      │
│  1. Verifica / instala Node.js si no lo tienes                  │
│  2. Instala las dependencias de Electron (npm install)          │
│  3. Lanza COFIPIA Desktop directamente (npm start)              │
│                                                                 │
│  Resultado: La app se abre en tu PC. No genera ningún .exe.     │
│  Requiere: Node.js, carpeta con código fuente completo.         │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  CONSTRUIR_INSTALADOR.bat                                       │
│  ─────────────────────────────────────────────────────────────  │
│  USO: Para DISTRIBUIR la app al Ejército u otros usuarios.     │
│                                                                 │
│  Qué hace:                                                      │
│  1. Compila toda la app en un instalador profesional            │
│  2. Genera COFIPIA-Setup-1.0.0.exe                              │
│  3. Lo copia automáticamente a tu carpeta Descargas             │
│  4. Abre la carpeta Descargas para que lo encuentres           │
│                                                                 │
│  Resultado: Un .exe en Descargas listo para instalar en         │
│  cualquier PC con Windows — sin Node.js, sin código fuente.     │
│  Requiere: Node.js y electron-builder (se instalan solos).      │
└─────────────────────────────────────────────────────────────────┘

RESUMEN EN UNA LÍNEA:
  INSTALAR = para usarlo TÚ mientras desarrollas
  CONSTRUIR = para entregarlo al CLIENTE o al Ejército
